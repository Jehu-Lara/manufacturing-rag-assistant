Manufacturing Knowledge RAG Assistant

A bilingual, citation-mandatory RAG assistant over real manufacturing SOPs, equipment manuals, and quality/safety procedures — with threshold-based refusal when it doesn't know.

Hybrid Retrieval (BM25 + bge-m3) EN / ES FastAPI + Streamlit Groq + OpenAI fallback Docker

Why this project is different

  • Citations are never trusted from the LLM. The model only ever supplies a chunk_id; the document title, section heading, and revision shown to the user are always re-derived from the real retrieved chunk's metadata. This is the core anti-hallucination guarantee — a citation can't be hallucinated because it isn't LLM-generated text.
  • Refusal is a calibrated gate, not a prompt instruction. A cosine-similarity threshold on retrieval confidence decides whether the system even attempts an answer, before generation runs — swept and calibrated against a held-out eval set, not guessed.
  • The corpus is honestly labeled. Real public-domain U.S. federal documents (OSHA, DOE Fundamentals Handbooks, NIOSH, CFR) are mixed with clearly-labeled synthetic documents (fictional equipment manuals, sample work orders) to fill gaps public sources don't cover — every document is tagged public/synthetic and never presented as something it isn't.
  • Bilingual end to end. Ask in English or Spanish; the answer comes back in the question's language; citations always point to the original English source document.

Stack

Retrieval: BAAI/bge-m3 multilingual embeddings, ChromaDB, rank-bm25, Reciprocal Rank Fusion.

Generation: Groq (openai/gpt-oss-120b) primary, OpenAI gpt-4o-mini fallback, structured JSON output with schema validation and repair-retry.

Backend: FastAPI, Pydantic, rate limiting, structured JSON logging.

Frontend: Streamlit, bilingual (EN/ES) toggle.

Deploy: single Docker image (nginx + uvicorn + Streamlit), targeting Oracle Cloud's Always Free Ampere A1 (ARM) tier — ARM64 wheel compatibility verified for every native dependency before provisioning.

Tests: 168 passing — ingestion, retrieval, eval metrics, and generation orchestration are real integration tests against real models/indexes; only live third-party LLM API calls are mocked, for cost and determinism.
